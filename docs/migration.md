# 旧版能力迁移映射

对照基线：`0702fee6ee28b01ea013292e175ad7babdd6d39e`。独立能力验证与基础闭环不代表原场景的完整功能已迁移。阶段编号仅用于本计划；当前目录、功能和命令见 [README](../README.md)与[架构约定](architecture.md)。

## 重构要求

**本清单中的每项迁移都必须同时满足[重构设计与验收原则](architecture.md#重构设计与验收原则)。** 实现前先明确职责、数据所有权、依赖与失败边界，并检查现有代码和旧项目中可复用的设计；推进过程中持续清理重复代码、不清晰的接口、失效注释、过时测试和文档。架构整理属于迁移本身，不统一推迟到功能补齐之后。

旧版作为功能与行为的对照依据；具体编辑器操作允许结合当前框架和使用体验重新设计。同一功能沿用旧版中文名称，按钮、属性、提示和文档同步核对；功能范围或数值含义变化时按[界面术语对照](architecture.md#中文界面与旧版对照)明确说明差异。新增代码或抽象应说明实际用途，已被替代的实现及时移除，正式工程不保留演进阶段的专属结构。验收同时检查功能、结构质量、必要的行为测试和说明是否一致；尚未解决的设计问题及平台验证缺口应明确记录。

测试的新增、清理与组织统一遵循[单元测试约定](development.md#单元测试)，不因迁移阶段重复维护一套规则。

## 验收状态与能力映射

状态：未迁移 → 功能接通 → 自动回归通过 → 实际交互待验收 → 已验收。当前推进以实现及自动回归为主；需要人工操作或目标设备的验收暂时搁置，保持待验收，不用编译结果替代。

各项通用能力按 macOS/Metal、Windows/Vulkan、Linux/Vulkan 共同维护；迁移验收需分别记录编译、CPU 回归、原生链接和 GPU/实际交互结果。交叉编译通过只完成对应检查，无法实测的平台保留待验收状态。

运行基础已接通固定步时钟、动作输入缓冲、UI 授权、宿主冻结恢复与暂停单步，并由 Editor Play 和 App 共用。Rapier 基础刚体、碰撞层、触发器、点关节/铰链关节/滑动关节及硬限位/驱动、胶囊走跑跳、蹲伏与站起空间检查、台阶/坡道/移动平台已接入；默认 demo 提供落体和角色操作，属性面板已支持作者根实体的刚体/角色创建、配置、撤销与保存；Rhai 已接通显式参数、独立实例状态、固定步/触发/启停回调、作者面板和包内源码产品。导航已接通单区域离线 Fixed Box 烘焙、非玩家胶囊绕墙及脚本巡逻/追逐/返回。声音已接通 PCM16 WAV 产品、2D 与点声源空间输出、相机监听及 Rhai 播放意图；离线混音、设备回调和人工试听分别验收，Windows/Linux 目标设备及三平台人工试听仍待验证。Rust 同名双关现已接通三目标收集、动画事件解锁出口及跨关进度；完整旧角色关卡、完整战斗、动态导航与完整旧双关玩法仍待迁移，下表完整能力的验收状态保持独立记录。
