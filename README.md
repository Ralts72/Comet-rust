# Comet Rust

Comet 的独立 Rust 3D 引擎工程，沿用引擎、编辑器、游戏与工具的业务目录，用 Cargo workspace 管理模块依赖。旧 C++ 工程用于行为对照，新工程不链接其引擎或 C/C++ 第三方实现。

编辑器界面使用简体中文，内置中文字体，独立游戏包无需另行安装字体。当前支持 glTF/GLB 静态与蒙皮模型导入、单片段播放与参数动画控制器、多材质 PBR/阴影、场景编辑、撤销/重做、保存与独立游戏打包。桌面共同支持目标为 macOS、Windows、Linux；macOS 使用原生 Metal，Windows/Linux 使用原生 Vulkan，暂不接入 DX12。Metal 已实际运行，Windows/Linux 已纳入交叉编译检查，目标设备运行仍需验证。Rhai 游戏脚本、文字 HUD、离线静态导航、2D 与点声源空间音频已接入；完整角色动画系统和旧玩法仍待迁移。
Editor Play 与 App 共用 60 Hz 固定步、暂停单步、失焦冻结及动作输入消费；长帧补步有上限并记录掉时。Rapier 已接入基础刚体、碰撞层、触发器、胶囊角色，以及点关节、铰链关节和滑动关节；默认 demo 可观察落体，Play 和独立游戏均可操作角色。编辑器关闭窗口时检查未保存的场景，支持保存后退出、直接退出或取消；保存失败保留窗口。视图内容错误同样保留编辑器和作者事务，显示诊断以便修复或撤销；Play 出错时停止运行并返回作者世界。

## 开发与启动

使用 `rust-toolchain.toml` 固定的 Rust 工具链、Edition 2024 和 `Cargo.lock`。启动与验证工具使用 Python 3 标准库。workspace 共用根 `target/`，编译并行配置在 `.cargo/config.toml`；macOS 最低为 14.2，需要 Xcode Command Line Tools 提供 SDK 与链接器；Linux 构建音频需要 `pkg-config` 和 ALSA 开发包（Debian/Ubuntu 为 `libasound2-dev`）。

日常只保留一个启动入口：

Editor 是编辑器，App 是独立游戏运行程序；Debug、Release 分别表示它们使用的构建配置。App 的源码入口位于 `app/`，Cargo 包和可执行文件名为 `comet-app`。

```sh
./start.sh                    # 准备 Debug Editor、Release App 模板，启动编辑器
./start.sh --help
./start.sh --project /path/to/project --scene main.scene
```

Windows 原生终端运行 `python tools/launch/launch.py`，与 `start.sh` 共用全部准备和启动逻辑；Windows 构建使用 MSVC 工具链和 Windows SDK，运行需要支持 Vulkan 的显卡驱动。没有额外的构建模式或 App 启动入口。

脚本通过 rustup 准备锁定工具链，按顺序构建两个程序，从 Cargo JSON 获取实际路径；首次需要编译两套依赖，后续复用缓存。构建配置统一由根 `Cargo.toml` 管理，没有动作分发或模式切换。默认项目为 `demo/`，开发产品位于 `target/products/demo/`。
macOS 启动时自动准备带原版蓝色彗星图标的 `Comet Editor.app`；导出 App使用原版橙色彗星图标。两套图标分别由 `editor/resources/icons/` 和 `app/resources/icons/` 管理，PNG 嵌入程序供桌面窗口及 Windows 任务栏使用，ICNS 随 macOS App 分发。Windows 启动时将原版 ICO 写入编辑器和 App 的独立程序副本，导出 App复用带图标的 App；Windows 原生显示仍待实机验收。

在编辑器“项目 → 项目设置 → 游戏图标”中选择项目 PNG，选择后自动保存到项目根 `project.json`，通过资产 UUID 引用，PNG 与 `.meta` 一起移动可保留配置。项目配置还保存稳定的 GameId，供包外存档识别游戏；新项目创建时分配，旧项目首次在 Editor 打开时迁移一次，普通资源构建不改配置。请将 `project.json` 随项目维护，改入口场景、搬移游戏包或更新程序不会更换身份。建议使用 1024 × 1024 像素图像；导出生成 PNG、macOS ICNS 和 Windows EXE 图标，App 窗口/任务栏同步使用项目图标。未配置时使用 Comet 默认图标，Editor 图标与原始 App 模板保持不变。demo 的图标位于 `demo/assets/icons/game.png`；导出 App不需要 Python。
准备好的 Editor 与 App 模板成套保存在 `target/launch/slot-*/programs/`，连续构建复用空闲槽，相同输入直接复用，源码变化时校验完整候选后替换。运行中的编辑器持有槽位锁，直到退出才允许复用；同时运行多个编辑器会使用独立槽，槽数量随同时使用量增长。模板记录源码/依赖/配置指纹、平台架构、协议版本和程序摘要；包含未提交源码，不以 Git commit 代替构建身份。身份只编入 Editor/App 入口，未修改的引擎库可复用 Cargo 缓存；测试目录和独立 `tests.rs` 不影响生产身份。修改程序源码后重新运行 `start.sh`，资源变化则由编辑器导出时重新构建。

在编辑器中点击“运行”后，WASD 按相机方向移动，Space 跳跃、Shift 跑步，右键拖动环绕、滚轮缩放；相机跟随角色。Ctrl 控制胶囊蹲伏，低顶下松开仍保持蹲伏，离开障碍后再站起；属性面板可配置蹲伏速度和高度比例。默认主场景使用方块外观；`character.scene` 双关使用旧项目的人形模型，按实际移动、着地、上升和蹲伏状态切换动作；手柄和完整玩法仍待接入。
工具栏提供“新建场景”和“打开场景 / Prefab”，也可使用 Ctrl/Cmd-N、Ctrl/Cmd-O；保存按钮随当前文件显示“保存场景”或“保存 Prefab”。新建时指定 assets 内的 `.scene` 位置，立即保存空场景和稳定的 `.meta` 身份，不覆盖已有文件；打开列表包含场景和原生 `.prefab`。有未保存修改时，可保存后切换、放弃修改后切换或取消。候选加载失败保留当前文档与 Play，成功后使用独立撤销历史。打开场景会选中对应导出入口；打开 Prefab 保留有效的场景选择，项目没有场景时不能导出 App。

项目面板点击“新建 Prefab”，可在 assets 内创建并打开空 `.prefab`，再添加实体和组件；已有原生 `.prefab` 可选中后点击“编辑源”。两者共用未保存确认、撤销、保存和独立运行预览，允许多根实体；保存保留 metadata 与源 UUID。保存后“刷新资源”，或重新打开引用它的场景，即可看到更新。不能将自身或间接引用自身的资源加入 Prefab。glTF/GLB 仍由外部工具维护，不提供源写回；从实例应用覆盖和跨层结构编辑尚未接入。

右键层级中的作者实体，选择“保存为 Prefab...”，输入 assets 内的 `.prefab` 位置并保存，可将这棵子树创建为独立 Prefab。保留实体 UUID、根的局部变换与子实例关联，父级不写入；指向子树外实体或外部场景实体的引用会被拒绝。保存不覆盖已有文件，不改写当前场景、选择或撤销历史；失败可在同一窗口修改路径后重试。完成后“刷新资源”，即可从项目面板放置或编辑新资源。直接实例根请先解除关联。

“项目”菜单提供新建和打开项目，快捷键为 Ctrl/Cmd-Shift-N、Ctrl/Cmd-Shift-O。可手动填写路径，也可通过内置浏览器选择目录；新建时选择父目录会保留填写的项目名。打开现有项目时，可在其 `assets/` 内浏览 `.scene` 或 `.prefab`，也可填写相对路径，默认 `main.scene`。浏览器支持目录跳转、刷新及 Windows 驱动器导航。新项目只包含空场景、身份文件和默认设置，必须使用尚不存在的目录。确认保存或放弃修改后，编辑器在后台创建、构建并校验候选，成功才结束旧 Play 并切换；失败保留当前会话。取消只放弃切换，后台会完成准备，已创建项目不会被删除。初始项目继续使用启动器指定的产品目录，其他项目使用初始产品父目录下 `projects/<路径摘要>` 的独立缓存，作者目录内不写构建产品。

普通 GUI 启动会在“项目 → 最近项目”记录最近成功打开的十个项目及各自最后一个 Scene/Prefab 文档；点击条目仍经过未保存确认和正常加载校验，“移除”只删除记录。记录失败在项目菜单单独提示，不影响已经打开的项目。headless、smoke 和命令行导出不读取或写入用户记录；启动项目仍由启动参数决定。本机记录位置见[开发文档](docs/development.md#项目浏览与本机记录)。
属性面板可为作者根实体添加、移除刚体和角色控制器，配置运动类型、碰撞形状、过滤层及角色参数；连续拖动合并为一次撤销，保存后供 Play 和导出使用。运行期间物理配置只读；Prefab 实例保留已有字段覆盖，组件结构在源 Prefab 中维护。 选中直接 Prefab 实体后，展开属性面板末尾的“实例覆盖”，可按字段或全部“恢复继承”，每次操作一条撤销；恢复后跟随源值更新，不修改源 Prefab。与源值相同的已有覆盖仍保留，直到明确恢复；Play 隐藏该作者操作。
同一根刚体可以添加点关节、铰链关节和滑动关节，选择世界、另一个作者刚体或同一直接 Prefab 内的刚体作为连接端；删除目标后显示未绑定。铰链关节/滑动关节可配置硬限位、速度或位置驱动；位置驱动使用频率和阻尼比，最大力矩与最大驱动力分别以 N·m / N 表示。铰链关节界面以度显示，关节轴为各局部坐标系的 X 方向。连接目标改变时保留当前世界锚点和朝向。打开 `joints.scene` 可观察摆动与滑动关节驱动，复用原有模型和材质；软限位和受力断裂尚未接入。

打开 `navigation.scene`，NPC 会绕墙在 A/B 标记之间巡逻，到点等待 1 秒再折返；用 WASD 靠近约 6 米触发追逐，远离超过 11 米后 NPC 返回 A 点并恢复巡逻。路线和距离、等待参数位于 `scripts/npc_patrol.rhai` 的显式参数中，A/B 使用实体引用，Edit 中移动标记即可调整路线；暂停、单步和 R 重开共用正常运行流程。脚本只改变运行意图，停止 Play 保留作者配置。

打开 `collect.scene` 并运行，用 WASD 走近金色方块：HUD 从 0/1 更新为 1/1，目标外观隐藏，旁边的蒙皮模型播放一次动作并响起提示音；离开再进入不会重复收集。等 HUD 提示动作完成，再重新按 E 前往现有第二关；提前按下或持续按住 E 不会自动换关。脚本显式记录已收集进度，继续时回到保存关卡起点，目标不重生，也不重播提示音或动作。R 恢复本次入关进度，正常新 Play 从空进度开始；停止 Play 保留作者文档。示例复用现有方块、SimpleSkin 产品和提示音；导出时需包含 `collect.scene`、`travel_second.scene` 及第二关返回的 `travel.scene`。

运行 `./start.sh --scene character.scene` 可进入双关三目标玩法：人形角色支持待机/走路/跑步的一维混合、蹲伏/蹲行、跳跃与下落过渡，地面移动时由动画事件播放空间脚步提示音。每关收集三个目标，每个目标独立播放 SimpleSkin 动作和提示音；收到三个“动作完成”事件后，出口闸门连同碰撞体升起。走到出口重新按 E 前往另一关，持续按住 E 不会自动跳关。第一关含台阶与蹲伏通道，第二关含绕行墙；使用现有 WASD、Space、Shift、Ctrl 与鼠标相机操作。F5 保存、F9 继续会从保存关卡入口重建，已收集目标保持隐藏且不重播反馈；两关进度分别保留，R 恢复本次入关基线。导出时同时包含 `character.scene` 和 `character_second.scene`。资源来源见 [示例资源说明](demo/ASSET-CREDITS.txt)；分层动画、挂点、粒子、章节 UI、手柄和完整设置仍待迁移。

打开 `animation.scene` 并运行，可观察官方 SimpleSkin 蒙皮模型随骨骼弯曲；暂停、单步和 R 重开共用正常运行流程，导出包只读取构建产品。示例源在 `demo/assets/models/simple_skin/`，测试复用同一份资产。属性面板“动画”可选片段、循环、速度及骨骼绑定，“蒙皮”可选同骨架的动画实体；强引用仍有效时，缺失或过期的源绑定表可显式重建并撤销。支持 STEP/LINEAR/CUBICSPLINE 的单 Clip TRS 播放；脚本可重播、暂停、继续、设置速度并查询已发布的播放状态，示例见 `collect.scene`。动画片段支持由 glTF `animation.extras.comet_events` 定义的阶段事件，脚本通过 `on_animation_event(ctx, animator, name)` 消费；暂停、单步和重播共用固定步流程。同骨架的 `.ani` 动画控制器支持参数、条件转换、一维混合与可打断过渡；属性面板可选择控制器，运行时显示状态与过渡进度。根运动、分层、重定向和 IK 尚未接入。

属性面板可配置导航区域和 NPC 的默认目标实体：每个场景一个轴对齐根区域，保持单位旋转和缩放，离线烘焙仅收集区域内的固定长方体碰撞几何。编辑完成后在区域的“导航”面板烘焙到 assets 内的 `.nav`；后台匹配候选成功后绑定资源，绑定支持撤销，再保存作者文档。修改静态几何或区域参数需重新烘焙；未烘焙和过期配置可以保存，Play 和导出会拒绝使用。运行期间固定刚体与区域位置不可改；动态切割、多区域、跳跃连接及完整旧导航场景尚未迁移。导航的目标平台 GPU 与人工交互仍需分别验收。

运行 `./start.sh --scene audio.scene` 可打开声音示例：进入 Play 后背景音循环，脚本播放一次提示音；E 重播提示音，Space 停止提示音，R 重新初始化本次运行。`audio/ambient_loop.wav` 与 `audio/play_chime.wav` 分别由音频源组件和 `scripts/audio_demo.rhai` 驱动。

将单/双声道 PCM16 `.wav` 放入 assets，刷新资源后可在属性面板“音频源”中选择“音频片段”并“添加音频源”，配置音量、循环和“启动时播放”；增删及修改支持撤销，直接 Prefab 只覆盖已有字段。新组件默认 2D；勾选“空间音效”后，按实体世界位置和当前视图相机的监听位置、朝向计算声像及距离衰减。“开始衰减距离”和“最大距离”以米计，默认 1 和 30，要求近距离小于远距离；空间播放会把立体声合为单声道，2D 保留原声道。距离区间内使用固定分贝曲线，中点幅度约为近距的 3.16%，到远距离后静音。

运行 `./start.sh --scene spatial_audio.scene` 可打开空间声示例：同一段提示音循环，发声实体以 3 米半径移动；E 开关声音，拖动视角可比较相机监听变化。它复用 `audio/play_chime.wav`，不新增一份录音。每个实体一个声音，重播替换旧声音；自然结束不会逐帧重播，暂停时请求的新播放等待恢复。Play 中组件配置只读，可用“播放声音／停止声音”改变运行意图；旧 2D 场景保持其作者版本，使用空间配置时升级并可撤销。空闲不打开设备，设备或空间参数不可用会显示诊断并继续画面；目标设备与人工试听分别验收，流式播放、遮挡和多监听器尚未接入。

层级面板点击“创建实体”可新建空实体，右键作者实体可创建子实体、复制或删除；将作者实体拖到另一个作者实体上可调整父级，拖到“场景根节点”可取消父级，操作保持世界变换并支持撤销和重做。会产生层级循环、破坏物理根节点或无法用局部 TRS 保留姿态的操作会被拒绝。删除实体时一并删除其子实体及挂接的 Prefab，并清除场景内指向它们的本地引用。Prefab 的实际根实体可复制或删除整个实例，包括多根及纯嵌套根；同实例多根同选只操作一次，复制保留所选根及主选映射。右键实际根实体可选择“解除模型关联”或“解除 Prefab 关联”，只解除当前这一层；直接实体成为可编辑作者实体，嵌套实例保留关联，当前姿态、引用和实体身份不变，支持一次撤销。同一实例的多个根可一起操作，不同实例请分别解除。关联保留时，内部结构仍在源文件维护。含刚体、角色或导航区域的资源直接放在场景根，保持对应根约束；普通模型继续使用作者容器。

空实体可在属性面板“网格渲染”中选择网格和材质，点击“添加网格渲染”或“移除网格渲染”；资源列表显示来源文件及 glTF 子资产名称。已有模型可以更换网格、材质，并调整 0～1 的粗糙度，每次操作支持撤销。新模型采用所选材质的粗糙度，后续更换材质保留实体已有的粗糙度。直接 Prefab 可覆盖已有模型字段，组件增删仍在源文件中维护；运行期间配置只读。

属性面板顶部可重命名作者实体；连续输入合并为一次撤销，Enter 或失焦提交，Escape 取消本次输入，UUID 保持不变。Prefab 内部实体名称仍在源文件中维护。视口上方可开启“移动吸附”并设置步长（默认 0.5 世界单位），世界模式沿世界轴吸附绝对网格；局部模式沿主选实体方向，从本次拖动起点按步长吸附位移。拖动时锁定设置，Escape 可取消整次移动。

右键作者实体选择“批量放置...”，设置“新增份数”（1～1000，默认 3）和“每份间距 XYZ”（世界坐标，默认 2、0、0），点击“放置”生成整组副本。第 n 份相对原组移动 n 倍间距，保留各自父级、组内相对位置和引用，挂接的模型/Prefab 实例一起复制；整批一条撤销。取消或 Escape 不生成副本，切换选择、文档、资源版本或失焦会取消窗口。直接 Prefab 根请先解除关联；奇异父级、精度不足、数值溢出或复制角色/导航区域违反唯一性时整批拒绝。

层级中 Ctrl/Cmd 点击切换多选，Shift 点击按显示顺序范围选择；视口 Ctrl/Cmd 点击也可切换选中。Ctrl/Cmd-A 全选，Ctrl/Cmd-D 复制选择，Delete 删除选择；文本输入期间不会触发实体复制/删除。多选支持整组层级拖放、复制、删除和移动，每次操作一条撤销，父子同时选中不会重复处理。移动共用主实体坐标方向，保持实体间偏移；选中作者容器或 Prefab 根时，可视后代一起高亮。运行期间禁用成组移动；Prefab 内部结构仍由源文件维护，混入不可操作实体时整组拒绝。

多选属性面板提供“共同属性”的位置、旋转和缩放，以主实体显示并标记“多值”。输入或拖动一个轴，只把该轴的数值同步到各实体，其余轴保留各自值；数值始终属于各自的局部坐标，父子同选会分别修改两者的局部字段。输入主实体的已有数值并按 Enter，也可将多值统一；无效输入被拒绝后，确认不会改用回退显示的数值。

所有选中实体都拥有对应组件时，还可共同调整粗糙度、刚体质量与摩擦系数、角色的移动/跳跃/蹲伏速度与蹲伏高度比例，以及音频源的音量和距离、导航代理的到达距离、动画播放器的播放速度。音频循环/启动时播放/空间音效、启用脚本、启用导航代理和动画循环支持混合状态；点击开关把整组统一为主实体当前值的反值，每次操作一条撤销。全部选中音频源都关闭空间音效时，距离控件禁用；调整距离必须符合每个实体的衰减区间约束。

网格渲染还支持共同替换网格与材质，列表继续显示来源文件和子资产名称，多值时选择主实体当前的资源也可统一整组。更换资源保留各实体已有的粗糙度，每次选择一条撤销；打开列表或 Escape 关闭不修改文档。所选产品、纹理引用或任一目标的绘制变换无效时整组拒绝。

音频片段、脚本资源与动画播放片段也可共同选择，保留各自的音量/空间配置、启用状态、脚本参数及动画绑定/速度。动画列表只提供所有选中骨架都兼容的片段；启用控制器时，片段与循环由状态定义，共同编辑不覆盖这些设置；骨架不同时仍可统一选择“不播放片段”。已有蒙皮绑定的模型更换网格时会检查兼容性，不兼容则整组拒绝。全部选中实体都属于直接 Prefab 时，末尾“实例覆盖”可按字段或全部恢复所选实体的继承，每次一条撤销，未选中节点的覆盖保留。

作者实体与直接 Prefab 可以一起编辑；候选不符合角色等约束，或包含不可编辑的嵌套实例时整组拒绝。数值连续修改形成一条撤销，Escape 恢复整组；返回各自起始值保留原有覆盖与继承。Play 中共同属性只读，组件增删、骨架/蒙皮等其他资源及其余字段的成组编辑仍待接入。

Edit 中从视口手柄以外的位置左键拖动可框选，Ctrl/Cmd 或 Shift 框选切换框内实体，Escape 取消。释放时按视锥内的实际三角几何查询，可以包含遮挡实体；拖动手柄仍优先执行变换。框选不修改作者文档或历史，Play 保留鼠标玩法输入。

视口工具栏可切换“移动”、“旋转”和“缩放”，Edit 中可按 W/E/R 切换；文字输入、活动拖动、弹窗和后台处理期间不切换工具。Play 保留游戏按键，R 仍用于重开。移动和旋转共用“世界／局部”选择；局部方向跟随主选实体的层级旋转，忽略缩放与镜像。两种模式都以主实体为轴心，同时旋转操作根与组内偏移；可开启角度吸附（默认 15°）。连续拖动形成一条撤销，Escape 恢复整组；父子同选只旋转最高操作根。作者实体及直接 Prefab 使用同一候选校验，非均匀父级造成剪切或违反角色直立等约束时整组拒绝。Play 中仅支持单个非物理实体；相机或视口尺寸改变、宿主失去活动时取消拖动。缩放提供主实体本地 X/Y/Z 轴手柄与中心统一倍率，围绕同一轴心变换整组，倍率吸附以 1 为原大小（默认步长 0.1）。倍率保持正数，保留既有反射符号和零轴；局部基不可逆时仅提供统一手柄，需要剪切、跨过零或溢出的候选整组拒绝。球体和胶囊仍要求等比缩放，Play 只编辑单个非物理实体。切换工具或旋转坐标系会取消当前拖动，需要松开后重新按下。

运行期间按 R 或点击“重开”，恢复当前关卡的入关场景、物理状态和显式进度，暂停时重开仍保持暂停。独立游戏也使用 R；输入被界面占用或宿主失焦时不响应，重开不读取磁盘存档。

运行场景时按 F5 保存单槽检查点，按 F9 从保存关卡入口继续，恢复脚本显式记录的进度。Editor 使用本次预览的内存槽，Stop 后清空，Prefab 预览不支持；导出 App把检查点放在用户游戏数据目录，搬动游戏包不影响存档。App 的 `--data-dir` 可指定隔离的存档与设置根目录。继续失败保留当前运行，不会覆盖作者文档；完整运行快照和多槽尚未接入。

导出 App按 Esc 打开暂停菜单，可返回游戏、保存进度、继续存档、修改设置或退出。设置提供主音量（0～1，默认 1）和方向光阴影（默认开启）；只有点击“应用”才保存并生效，返回会放弃尚未应用的修改。主音量作用于全部 2D 和空间音效，阴影开关保留方向光照；设置随 GameId 保存在包外，换关和重开保持。菜单关闭后仍遵守原来的暂停状态，Editor 的预览设置不受影响。坏设置文件保留原文并提示，需修复或移走后重试；完整画质、分类音量与显示设置仍待迁移。

打开 `travel.scene` 或 `travel_second.scene`，运行后按 E 在两关间切换；停止 Play 回到原作者文档，历史与未保存内容保留。导出这个示例时将另一关加入“额外场景”；游戏只允许切换到包中明确包含的场景。加载失败在脚本日志显示，当前关继续运行。显式脚本进度随成功换关保留，完整旧关卡仍待迁移。

项目 `assets/` 中的 `.rhai` 文件与 `.meta` 一起维护，刷新资源后可在实体属性的“脚本”中选择，配置启用状态及布尔、整数、数值、文本、三维向量或实体参数。作者实体支持添加/移除和参数编辑，Prefab 实例可覆盖脚本资源及启用状态，参数结构在源 Prefab 中维护；运行期间配置只读。底部“脚本日志”显示生命周期日志与错误。脚本随依赖产品进入导出包，无需在玩家设备上安装解释器；修改源码后刷新资源并重新 Play，当前会话不热替换正在运行的脚本。

回调为 `on_start(ctx)`、`on_fixed_update(ctx, dt)`、`on_trigger(ctx, other, entered)`、`on_stop(ctx)`，可按需定义。实例用 `this` 保存运行状态，用 `ctx.param("名称")` 读取显式参数；每个绑定独立持有状态，停止后丢弃，重开重新初始化。可查询输入与局部位置/旋转/缩放，提交非物理实体变换、材质粗糙度、物理命令及输出日志。`ctx.request_scene(ctx.param("next_scene"))` 可请求换关，参数为场景 UUID 文本；返回 true 表示本次回调接受请求，整次回调成功后才交给宿主加载。文本参数不会自动收集目标场景依赖，导出仍需明确包含它；详细契约与限制见[脚本生命周期](docs/architecture.md#脚本生命周期)。默认示例在运行中按 E，对落体方块施加向上冲量。

项目面板显示项目中已构建的 glTF/GLB 模型与 Prefab；选择后点击“添加到场景”或双击资源，即可创建可移动的实体容器并挂接资源实例，操作支持撤销。将源资源放入项目 assets 后，点击“刷新资源”在后台构建并更新列表与场景，无需重启；已有资源随 metadata 保持 UUID。刷新不自动保存作者场景，失败保留当前文档与已接纳资源。运行期间需先停止 Play，处理时暂时禁用编辑、切换和导出。拖放、外部文件导入界面与自动文件监听尚未接入。
“导出 App”窗口选择启动场景、额外场景和新输出位置，提供 “导出”、“导出并运行”。导出会结束 Play、提交编辑事务并保存作者场景，再后台构建资源和打包；窗口显示阶段、日志和失败原因，任务期间暂停修改操作。日常“保存”只保存作者内容。
macOS 默认导出 `.app`，资源放在 `Contents/Resources`，发布前完成本机临时签名与校验；其他目录形式也可导出。游戏直接运行导出包，不依赖 Cargo、开发目录或编辑器进程。正式输出必须尚不存在，完整候选通过后才整体发布。对外分发的证书签名、公证与安装器尚未接入。

项目、产品、截图、报告和导出目的地的相对路径以调用目录为基准；作者场景路径统一限制在项目的 `assets/` 内，打开、保存和导出都会校验。产品缓存目录不能与作者资源目录相互包含，编辑器与资产 CLI 共用此规则。公共启动实现位于 `tools/launch/launch.py`，只使用 Python 3 标准库。

| 配置 | 用途与取舍 |
| --- | --- |
| Debug | 编辑开发；本仓库代码保留完整调试信息、断言、溢出检查与增量缓存，第三方依赖关闭调试信息 |
| Release | 游戏运行与分发；优化等级 3、Thin LTO、剥离符号、关闭增量编译，保留默认并行 codegen 与 panic unwind |

测试继承开发配置；配置统一在根 `Cargo.toml`，选项含义见 [Cargo Profiles](https://doc.rust-lang.org/cargo/reference/profiles.html)。`target/` 包含缓存、测试和验证输出，不作为发布包。定期检查并清理过期缓存和旧程序快照，保留正在使用的产物；具体规则见[构建缓存维护](docs/development.md#构建缓存维护)。

作者资产及其 `.meta` 身份文件需要一起入库，包括 glTF 配套的 `.bin`、纹理和测试数据；`Cargo.lock` 也保留在版本控制中。
自有作者格式使用 `.scene`、`.prefab`、`.mesh`、`.material`、`.ani`，烘焙导航保存为 `.nav`，内容均为 JSON；`.nav` 与其 `.meta` 一起保留，重烘焙更新同一资产。默认场景为 `demo/assets/main.scene`；metadata 在完整源文件名后追加 `.meta`，例如 `main.scene.meta`、`showcase.gltf.meta`，重命名时随源文件一起移动并保留 UUID。
可再生产品、截图、报告与诊断输出放在 `target/`，导出包可放在 `target/packages/` 或根 `dist/`。根 `target/`、`products/`、`dist/`，以及构建锁、原子写入临时文件、GPU 捕获包和 Python 缓存由 `.gitignore` 排除；运行证据保存在 `target/` 或 CI 附件，不放进文档目录或版本控制。

## 验证与资产工具

```sh
cargo test --workspace --locked
python3 tools/verify/verify.py                         # 格式、测试、Clippy、边界、依赖、构建和独立包验证
python3 tools/verify/verify.py --native --linux --windows # 本机 GPU/窗口、Release 游戏、Linux/Windows 交叉检查
cargo run -p comet-gpu-check --locked           # 原生 GPU 能力检查
cargo run -p comet-assetc --locked -- prepare demo --output target/products/demo
```

默认 `cargo build/test` 面向引擎库、编辑文档和资产工具；`--workspace` 包含编辑器、游戏和 GPU 工具，均为按功能组织的当前模块。

## Git 与协作配置

[.gitattributes](.gitattributes) 沿用旧仓库的 Git LFS 资产管理：模型二进制、纹理、字体和音频走 LFS；`.scene`、`.prefab`、`.mesh`、`.material`、`.ani`、`.nav`、`.rhai`、`.meta` 和 `.gltf` 保留普通文本 diff，文本统一为 LF。需要安装 Git LFS；已有克隆可在仓库内执行：

```sh
git lfs install --local
git lfs pull
```

CI checkout 会拉取 LFS 文件。第三方库由 Cargo 和 `Cargo.lock` 管理，没有 Git submodule 初始化步骤。[.editorconfig](.editorconfig) 统一编辑器的 UTF-8、LF 和缩进；本机 IDE 配置与缓存由 `.gitignore` 排除。
